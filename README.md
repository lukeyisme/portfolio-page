# Luke Curry's Personal Portfolio Website

## Purpose

This website is to serve as my personal and professional portfolio page for coding projects. It's intended audience is fellow software developers and engineers, as well as potential employers and other people who have a professional interest in me or my work.

## Languages and Frameworks

This project is intended to be built with vanilla HTML, CSS, and JavaScript where possible. Future updates may change to a web framework, but none is present at this time.

## Browser Requirement

MDN web documentation will be consulted to ensure that a majority of modern browsers support viewing and interacting with this website.
